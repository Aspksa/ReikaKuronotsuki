# Дизайн-система Reika

Ночь, лунный свет, жемчужное серебро, малиновые кисти, золото и сакура: палитра взята из арта Рэйки.
Живые примеры всех элементов: **`web/styleguide.html`** (открывается тем же сервером: `/styleguide.html`).

## Как устроены файлы

```
web/style.css          точка входа: только @import, порядок важен
web/css/tokens.css     ВСЕ сырые цвета, размеры, шкалы (единственное место)
web/css/base.css       сброс, типографика, .sr, переключатель «уменьшить движение»
web/css/sky.css        ночная сцена в стиле аниме: звёзды, луна, облака, море, лепестки, виньетка
web/css/layout.css     каркас: левое меню, область контента, главная
web/css/components.css кнопки, панели, карточки, поля, прогресс, подсветка .lit
web/css/chat.css       плавающий логотип и окно чата
web/css/update.css     страница «Обновление»
web/sky.js             жизнь сцены: звёзды и искорки, круги по воде, лепестки, метеор, параллакс, свет за курсором
web/shell.js           меню слева, маршруты, статус
web/orb.js             плавающий логотип (перетаскивание, клавиатура)
```

## Компоненты (`components.css`)

- **Кнопка** `.btn` + вариант: `btn--primary` (малиновая, главное действие), `btn--gold`, `btn--outline`, `btn--ghost`, `btn--icon`; размер `btn--sm`.
- **Поверхности** `.panel` (стекло с лунной кромкой), `.card` (`.card__label`, `.card__value`), окно чата `.chat-panel`.
- **Поле** `.field` (input/select/textarea), строка формы `.form-row`.
- **Прогресс** `.bar > div`. **Текст** `.text-muted`, `.text-warn`.
- **Свет за курсором**: добавьте класс `lit` на `.panel`, `.card` или пункт меню, `sky.js` сам задаст `--lx/--ly/--lit`.

## Ночная сцена и игра света (`sky.css`, `sky.js`)

Слои сзади вперёд: звёзды и искорки → свечение горизонта → луна (`glow`, `rays`, два кольца, `disc`, `bloom`, `flare`) → облака → море (лунная дорожка, три слоя волн, круги и блики) → дымка → лепестки → виньетка.

- Картинки сцены нарисованы векторно (`web/assets/scene/`): `moon.svg` (кремовая луна с мягкими «морями» и кратерами, тень справа снизу), `cloud.svg` (облако с тёплой подсветкой краёв), `waves.svg` (бесшовная плитка волн, ширина кратна периоду 80 px), `moon-path.svg` (лунная дорожка штрихами), `sparkle.svg` (звезда-искорка).
- Логотипы лежат в `web/assets/logo/` (из набора `kitsune_lux_logos`): `brand.webp` (меню), `orb.webp` (плавающий значок), `logo-256.webp`, `favicon.ico`, `windows.ico`.
- Свет «дышит» (`breathe`), лучи очень медленно вращаются, облака проплывают перед луной, волны текут с разной скоростью, по воде расходятся круги (`sky.js`), искорки пульсируют, изредка пролетает метеор.
- Сцена на несколько пикселей смещается за курсором (параллакс, `--px/--py`).
- Положение и размер луны задают токены `--moon-size/top/right`: от них считаются и лучи, и дорожка на воде, и подсветка воды.

## Правила (их проверяют тесты `tests/design.test.js`)

1. Сырые цвета (`#hex`) только в `tokens.css`. Прозрачные цвета: `rgb(var(--…-rgb) / α)`. Литералы `rgb(…)` допустимы только в `sky.css` (оттенки сцены).
2. Каждая `var(--x)` определена в CSS (или задаётся из JS: `--px --py --lx --ly --lit --s --c --h --d --delay --size --sway --w`).
3. `z-index` только через `var(--z-…)`.
4. Каждая анимация объявлена через `@keyframes`; «уменьшить движение» выключает всё одним правилом в `base.css`, а `sky.js` в этом режиме вообще не создаёт лепестки, метеоры и параллакс.
5. Контраст основных пар «текст на фоне» не ниже 4.5:1.
6. `--orb-size` равен константе `SIZE` в `orb.js`.
7. `styleguide.html` подключает тот же `style.css`.

## Как добавить экран или компонент

1. Возьмите готовые классы (`.panel`, `.btn`, `.card`, `.field`) и токены. Новые значения добавляйте в `tokens.css`, а не в файл компонента.
2. Стили экрана положите в отдельный `css/<экран>.css` и подключите в `style.css` после `components.css`.
3. Покажите новый компонент в `styleguide.html`.
4. Запустите `node tests/run.js`.
