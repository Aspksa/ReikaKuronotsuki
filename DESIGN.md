# Дизайн-система Reika

Минималистичный и единообразный стиль: плоские тёмные поверхности, тонкие рамки, один акцент (малиновый), без градиентов, свечения и размытия. Везде одни и те же высота контролов, скругления, размеры текста и отступы.
Живые примеры всех элементов: **`web/styleguide.html`** (открывается тем же сервером: `/styleguide.html`).

## Как устроены файлы

```
web/style.css          точка входа: только @import, порядок важен
web/css/tokens.css     ВСЕ сырые цвета, размеры, шкалы (единственное место)
web/css/base.css       сброс, типографика, .sr, переключатель «уменьшить движение»
web/css/sky.css        фон: тёмная подложка, лёгкие лепестки, виньетка
web/css/layout.css     каркас: область контента, главная
web/css/sidebar.css    левое меню: бренд, навигация, подвал («Обновления», «О проекте»), свёрнутый режим
web/css/components.css кнопки, панели, карточки, поля, прогресс
web/css/chat.css       плавающий логотип и окно чата
web/css/settings.css   страница «Настройки»: карточки сервера, чата, ИИ и данных
web/css/update.css     страница «Обновление проекта»: карточка состояния, шаги, карточки, история
web/css/stats.css      блок «Статистика проекта» на этой странице
web/stats-visual.js    значки, цвета и виды диаграмм показателей (чистые функции, тесты `tests/stats-visual.test.js`)
web/css/overlays.css   всплывающее: «Что нового», уведомления, окно «О проекте» (один общий вид)
web/sky.js             лепестки
web/shell.js           меню слева, маршруты, статус
web/orb.js             плавающий логотип (перетаскивание, клавиатура)
```

## Компоненты (`components.css`)

- **Кнопка** `.btn` одной высоты и формы: `btn--primary` (малиновая, главное действие экрана, оно одно), `btn--outline` (обычные), `btn--ghost` (тихие), `btn--icon`.
- **Поверхности** `.panel` (плоская, с тонкой рамкой), `.card` (`.card__label`, `.card__value`), окно чата `.chat-panel`.
- **Поле** `.field` (input/select/textarea), строка формы `.form-row`.
- **Заметка** `.callout` (`callout--warn` для ошибок и предупреждений). **Прогресс** `.bar > div`. **Текст** `.text-muted`, `.text-warn`.

## Фон (`sky.css`, `sky.js`)

Спокойный тёмный фон (`--bg`) с несколькими падающими лепестками сакуры и лёгкой виньеткой. Ночная сцена (луна, небо, звёзды, облака, море) убрана по просьбе.
Лепестки создаёт `sky.js`; при «уменьшить движение» их нет.

## Логотип

Набор `kitsune_lux_logos` (круглая эмблема в золотом кольце), файлы в `web/assets/logo/`: `brand.webp` (меню, рисуется 44 px, файл 88 px для чётких экранов), `orb.webp` (плавающий значок, 64 px, файл 128 px), `logo-256.webp`, `favicon.ico` (вкладка), `windows.ico` (трей Windows). Новый размер добавляйте в 2× от размера на экране.

## Правила (их проверяют тесты `tests/design.test.js`)

1. Сырые цвета (`#hex`) только в `tokens.css`. Прозрачные цвета: `rgb(var(--…-rgb) / α)`. Литералы `rgb(…)` допустимы только в `sky.css` (виньетка).
2. Каждая `var(--x)` определена в CSS (или задаётся из JS: `--size --sway`).
3. `z-index` только через `var(--z-…)`.
4. Каждая анимация объявлена через `@keyframes`; «уменьшить движение» выключает всё одним правилом в `base.css`, а `sky.js` в этом режиме вообще не создаёт лепестки.
5. Контраст основных пар «текст на фоне» не ниже 4.5:1.
6. `--orb-size` равен константе `SIZE` в `orb.js`.
7. `styleguide.html` подключает тот же `style.css`.
8. Минимализм: ни градиентов, ни свечения и размытия в интерфейсе, все размеры текста из шкалы `--text-*`, у кнопок и полей одна высота `--control-h`, старых декоративных токенов (`--gold`, `--blush`, `--rim-light` и т. п.) нет.

## Как добавить экран или компонент

1. Возьмите готовые классы (`.panel`, `.btn`, `.card`, `.field`, `.callout`) и токены. Новые значения добавляйте в `tokens.css`, а не в файл компонента.
2. Стили экрана положите в отдельный `css/<экран>.css` и подключите в `style.css` после `components.css`.
3. Покажите новый компонент в `styleguide.html`.
4. Запустите `node tests/run.js`.

## Статистика проекта: язык показателей

У каждого из 150 показателей свой значок по смыслу названия, свой спокойный цвет (семейство цвета на категорию, оттенок на показатель; `oklch`, яркость 0,71–0,83, насыщенность до 0,11) и диаграмма того вида, который подходит к данным. Диаграмма рисует только то, что есть в данных: нет истории, значит пунктирный контур, а не придуманная линия.

| Вид | Для чего |
|---|---|
| `area`, `bars` | сохранённая история (размер, файлы, строки, память, диск; установки, ошибки, скачивание) |
| `compare` | старт и сейчас (рост проекта) |
| `gauge` | доля в процентах (полукруг), `meter` — заполнение шкалы из 20 делений |
| `share` | часть от целого: «5 из 66 файлов» |
| `age` | давность на читаемой шкале: 24 часа или 7 дней |
| `pips` | небольшие счётчики: ровно столько точек, сколько число (до 10, дальше «+») |
| `signal` | порядок величины: байты по единицам (Б…ТБ) или число по разрядам |
| `scale` | логарифмическая линейка 0,1…1К для значений «на файл/на установку» |
| `toggle`, `chip` | да/нет и короткий текст |

Показатели разложены по семи разделам («Сейчас», «Файлы», «Особенности», «Код», «Установки», «Загрузки», «Версии»), каждый разделён на небольшие группы с заголовками; каталог лежит в `web/stats-catalog.js`. Разделы переключаются одной строкой вкладок, которая остаётся на виду при прокрутке (клавиши ← → Home End), последний открытый раздел запоминается.
