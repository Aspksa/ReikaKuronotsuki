# Reika Kuronotsuki

Виртуальная спутница Рэйка: чат в браузере, который запускается одним файлом.

## Запуск (Windows)

Дважды щёлкните **`Reika Kuronotsuki.bat`**. Что происходит:

1. Если Node.js нет, переносная версия скачивается в папку `runtime/` внутри проекта.
2. Запускаются тесты. Если хоть один не прошёл, запуск отменяется.
3. Окно скрывается, Рэйка работает в трее рядом с часами (двойной щелчок — открыть чат, правая кнопка — «Выход»).
4. Чат сам открывается в браузере.

Сервер слушает только этот компьютер (127.0.0.1). Если порт 8731 занят, берётся следующий свободный.

Настройки (порт) лежат в `config.default.json`. Чтобы изменить их, скопируйте файл в `config.json`: он ваш, не попадает в git и обновлением не затрагивается.

Проект можно копировать на флешку или в любую папку, включая путь с кириллицей и пробелами: все пути относительные. Если носитель только для чтения, данные пишутся в профиль пользователя.

## Интерфейс

Дизайн-система описана в [`DESIGN.md`](DESIGN.md), живые примеры: `/styleguide.html`. Стили разложены по слоям в `web/css/` (токены, база, фон, каркас, левое меню, компоненты, чат, обновление, всплывающее).

Дизайн взят из арта Рэйки: ночное небо с луной, жемчужное серебро, малиновые кисти, золото и лепестки сакуры.

- **Меню слева:** «Главная», «Чат с Рэйкой», «Обновление» (появляется, когда отвечает локальный сервер; красная точка значит «есть новая версия»). Меню можно свернуть до иконок, выбор запоминается.
- **Чат открывается через логотип** в углу (круглый значок с лисой). Его можно перетащить в любое место, он остаётся на всех страницах и запоминает позицию. Стрелки двигают его с клавиатуры (Shift — шагом крупнее), Esc закрывает чат. Окно чата открывается сверху, снизу или сбоку, чтобы не закрывать логотип.
- **Логотип** из набора `kitsune_lux_logos`: круглая эмблема в золотом кольце (файлы в `web/assets/logo/`: `brand.webp` для меню, `orb.webp` для плавающего значка, `favicon.ico`, `windows.ico` для трея Windows). Один и тот же логотип стоит в меню, на плавающем значке, на вкладке браузера и в трее. На главной нет ни названий, ни картинок: только кнопки и карточки состояния.
- Арт `web/assets/reika.jpg` используется только как аватар в шапке чата. Замените файл, если хотите другую картинку.
- **Фон:** спокойный тёмный, с падающими лепестками сакуры. (Ночная сцена с луной, звёздами, облаками и морем убрана по просьбе.)
- Всё движение (лепестки) отключается, если в системе включено «уменьшить движение».

## Обновление проекта

Пункт **«Обновления»** в подвале левого меню, над «О проекте» (только при запуске через `.bat` или `node launcher/boot.js`). Источник: `github.com/Aspksa/ReikaKuronotsuki`.

Состояние видно в меню по значку (стрелка вниз, галочка, вращение, предупреждение) и красной точке при новой версии; установить можно кнопкой в уведомлении или на странице. При наведении появляется карточка **«Что нового»** (последние изменения). Когда найдена новая версия или обновление готово, в углу появляется уведомление (о каждой версии один раз). В подвале меню: кнопка **«О проекте»** (версия, режим, ссылка на репозиторий).

**Обновление из файла** (без интернета, например с флешки): на странице обновления выберите ZIP проекта (на GitHub: Code → Download ZIP). Архив разбирается собственным строгим читателем (без шифрования, символьных ссылок и нестандартных методов), проверяется контрольными суммами и маркерами проекта, тесты запускаются в отдельной папке, данные и настройки не затрагиваются. Архив не сверяется с GitHub: ставьте только те, которым доверяете.

1. **Проверить:** сравнивает установленную версию с GitHub (канал «Свежий» — `main`, «Стабильный» — последний релиз). Автопроверка раз в час/сутки только ищет новую версию и ничего не скачивает.
2. **Скачать и проверить:** файлы идут в `.updates/staging`, каждый сверяется с Git-хэшем. Затем в этой папке запускаются тесты проекта. Установка заблокирована, пока CI коммита не прошёл (нужен успешный job `tests`).
3. **Установить и перезапустить:** лаунчер (`launcher/boot.js`) делает резервную копию изменяемых файлов и копию `data/`, пишет журнал, меняет файлы атомарно, проверяет результат и запускает новую версию. Если она не стартует или не отвечает на `/api/health`, прежняя версия (и данные) возвращаются автоматически.
4. **Откат** последней установки доступен в окне «Обновление». Он не трогает вашу историю чата.

Защита: файлы пользователя (`data/`, `config.json`, `.env`) обновление не трогает; удаление файлов только после вашего подтверждения; прерванная установка (отключение питания) восстанавливается при следующем запуске; две одновременные установки невозможны; проверяется свободное место.

Ограничения: тесты скачанной версии выполняют её код с вашими правами (CI и хэши не заменяют доверие к репозиторию); новый установщик начинает работать после полного перезапуска Рэйки; обновление требует интернета и Node.js.

## Веб-версия (без сервера)

Папка `web/` самодостаточна: откройте `web/index.html` двойным щелчком или выложите папку на любой статический хостинг (GitHub Pages, Netlify и т. п.). Движок ответов работает прямо в браузере, история хранится в `localStorage` на этом устройстве, и страница сама определяет, что сервера нет. С `.bat` или `node server/main.js` та же страница хранит историю на диске.

## Без Windows (Linux, macOS)

```
node tests/run.js && node launcher/boot.js
```

## Структура

- `core/` ядро: нормализация текста, эмоции, ответы, история
- `server/` HTTP-сервер и API (`/api/chat`, `/api/history`, `/api/health`)
- `web/` браузерный интерфейс и общий движок `reika-chat.js` (работает и в браузере, и в Node)
- `launcher/` запуск (`start.ps1`, трей) и `boot.js` (установка обновлений, откат)
- `update/` обновлятор (`updater.js`), установщик с откатом (`installer.js`), общие правила путей (`shared.js`)
- `tests/` тесты (`node tests/run.js`)
- `data/` история переписки (не попадает в git)
