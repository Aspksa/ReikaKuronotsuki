# Reika v31: artist layer preparation kit

Run `python tools/artist_kit_v31.py Reika_Kuronotsuki_Reference_v30.png output/reika_v31_kit` with the generated 1024×1536 reference image from the conversation. The output contains an untouched `reference.png`, a manifest and **17 entirely transparent named PNG canvases** of matching size.

This is a starting kit for manual drawing, **not automatic segmentation**. In particular, the v30 reference is a concept sheet with multiple panels and cannot simply be cut into a production-ready 17-layer Live2D rig. An artist must design a unified front view, separately draw the hidden portions of nine tails and hair, add expression variants and validate visual coherence before animating. Do not use the blank files as production art. The generated reference PNG is provided separately, not committed as a GitHub binary.
