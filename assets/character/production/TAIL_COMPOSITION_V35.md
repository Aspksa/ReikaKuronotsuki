# v35 — Nine-tail composition sandbox

The browser prototype now provides a **separate nine-tail composition editor** below the PNG layer player. Select nine experimental PNGs from v33, adjust each tail's horizontal and vertical position, rotation, scale and front-to-back order, then copy JSON configuration to the clipboard. Reset restores default placement. Each tail has a unique z-order.

This is a **flat visual mockup**, not a completed anatomical rig. Placement defaults are illustrative and may not align with a production torso. PNGs must be selected in desired index order. Nothing is uploaded to a server or saved persistently by this editor. The composition editor does not reconstruct obscured tail roots, remove segmentation artifacts or certify Live2D readiness.
