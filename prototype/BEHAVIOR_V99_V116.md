# Reika v99–v116: Emotional nine-tail preview

This package introduces 18 incremental, tested behavior features focused on matching animated tails to the **existing local rule-based emotional reaction**, including when the optional AI mode supplies a reply. Stages: v99 neutral fallback, v100 happy motion, v101 serious motion, v102 thinking profile, v103 magic profile, v104 concern classification, v105 magic classification, v106 thinking classification, v107 positivity classification, v108 unrecognized-text fallback, v109 interpolation endpoints, v110 interpolation validation, v111 default controller state, v112 changing target mood, v113 progressive blending, v114 settling at the target, v115 invalid time rejection, and v116 resetting the controller with browser tests.

The new **Эмоциональные хвосты** controls include an opt-out and adjustable reaction intensity. Changes honor the user's reduced-motion setting. The preview uses the nine loaded experimental PNGs; without PNGs it shows no new character art. The bridge reads the current chat mood rather than analyzing emotions with a new AI service. The code does not generate Live2D cutouts or accurately rig tail anatomy. Voice remains browser-based TTS with approximate mouth animation.
